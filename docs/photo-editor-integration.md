# Photo Editor 편집 통합

기반: [perioahn/photo-editor](https://github.com/perioahn/photo-editor), `ae420188736791bb9b9683e031aa3d854425e762` (2026-07-06).

`photoEdits.ts`와 `PhotoEditorCanvas.vue`는 이 버전의 Edits, 톤 LUT, 회전, 수평선, 크롭 캔버스를 가져와 정합기에 맞게 구성했습니다. `FixedEditor.vue`는 로컬 API에 연결합니다. 외부 페이지, iframe, NEF 추출, EXIF/JPEG 내보내기 의존성은 포함하지 않습니다.

- 원본 PNG를 읽고 원본에서 모든 조정값을 렌더합니다. 적용 시 풀해상도 PNG 한 장과 레시피를 전송합니다.
- `G`는 3×3 배열이며 `p_edit = G @ p_source`입니다. 정수 좌표는 픽셀 중심(OpenCV)을 뜻합니다. 90°/미세회전/반전 후 중심을 `(출력크기−1)/2`로 이동하고 정수 크롭 원점을 뺍니다.
- 반전은 원본 축에 적용한 후 90° 회전, 미세회전 순서입니다. 크롭은 정수 좌표로 정규화하고 클립합니다. 가로·세로 배율을 바꾸는 리사이즈는 없습니다.
- 밝기·대비는 G에 영향을 주지 않습니다. `/`는 현재 기하를 유지하며 보정 전 톤을 보여 줍니다. 원본 전체 보기는 별도 버튼입니다.
- 폼에는 읽기 시작한 `base_revision`을 담습니다. 다른 창에서 기준을 수정한 경우 서버가 오래된 편집을 거절할 수 있습니다.
- 적용 전 이력은 컴포넌트 안에서 50단계까지 유지합니다. 한 슬라이더 제스처는 한 단계, 크롭 적용은 한 단계이며 취소 시 진입 전 구도를 복원합니다. Ctrl/Cmd+Z와 redo는 상위 마스크 키 처리로 전달하지 않습니다.
- 미리보기는 최대 1600px로 캐시하지만 적용 결과는 원본 크기에서 생성합니다. 고해상도 PNG/G 일치는 실제 Chromium의 합성 표식 이미지로 확인합니다.

부모는 `image: {id,name,revision,edits}`와 `busy`를 전달합니다. `applied` 후 상태를 갱신하고 이전 Moving/비교 화면으로 복귀하며, `cancel`은 편집 초안을 폐기합니다. `error`는 메시지를 표시하되 편집기를 닫지 않습니다. 외부 탐색 중 초안을 보존하려면 편집기를 유지하거나 `dirty` 공개 값을 사용해 탐색을 제어합니다.

검증: `photoEdits.test.ts`는 80개 회전·반전·미세회전 조합의 직교성과 원본 좌표를 확인합니다. 인접 `photo-editor` 저장소의 `npm run test:integration`은 16개 90°/반전 조합에서 실제 PNG 표식 위치와 G를 비교하고 2049×1537 원본 해상도 출력을 검사합니다.
