# 마스크 없는 기본 정합의 영역 재탐색

요청: 자동 추천 버튼을 누르거나 마스크·앵커를 생성하지 않고, 마스크가 없는 일반 정합에서 자동으로 전역 대응을 수집하고 대응 영역을 원본에서 재매칭한다.

구현 범위:
1. 기존 피라미드/폴백에서 각 단계의 대응 후보를 원본 좌표로 보존한다. 무마스크 경로에서 동일한 global/masked 추론을 중복하지 않는다.
2. 공간적으로 분산되고 지역적으로 일관된 대응 묶음을 골라 양쪽 원본을 크롭한다. 추가 추론은 제한된 한 차례이며 시간 예산은 추론 사이에서 검사한다.
3. 중복을 제거하고 지역별 밀집도를 제한한다. 전역 검증점으로 기존 영역의 큰 악화를 막고, 별도 보존한 지역 검증점으로 실제 개선을 검사한다. 겹치는 크롭을 통한 검증점 재유입도 제거하며 검증이 부족하면 기존 결과를 보존한다.
4. 결과는 similarity만 허용한다. 선택 마스크·명시적 앵커 경로는 기존 사용자 의도를 우선한다. 내부 후보를 사용자 마스크나 앵커로 저장하지 않는다.
5. 합성 점 계약 테스트와 실제 LoFTR 합성 영상, API 회귀를 확인하고 로컬 실행본을 연결한다. GitHub 배포는 범위 밖이다.

완료: `1.5.1-local.5`, 로컬 실행본 `http://127.0.0.1:8794/`. 기존 8793의 작업 사진 3장은 유지했다. 기존 바로가기는 구버전 포트를 건너뛰고 새 버전을 재사용한다. UI 버튼 추가 없이 일반 정합에서 작동한다.

검증: 완료 조건 4개, 계약/API/기존 엔진 검사 65개 통과. 실제 LoFTR를 사용한 1440×960 합성 사진의 HTTP 기본 정합에서 크롭 4쌍을 탐색했고, 알려진 변환의 분산 검증점 최대 오차는 비교 경로 5.063px, 자동 경로 2.537px였다. 마지막 측정은 비교 경로 0.699초, 자동 경로 0.506초, 지역 단계 0.242초였다. 모델 로딩을 제외한 한 쌍의 측정으로 다른 사진이나 기기에서의 속도·정확도를 보장하지 않는다. 비교 경로는 이번 코드에서 지역 재탐색을 끈 경로이며 과거 바이너리의 측정이 아니다.

추가 추론은 최대 4쌍, 입력 장변 640, 시간 예산 6초를 추론 호출 사이에서 확인한다. 이미 시작된 추론을 강제 종료하는 절대 6초 제한은 아니다. 마스크가 하나라도 선택되거나 명시적 앵커를 전달하면 자동 무마스크 확장은 비활성화한다. 생성한 내부 대응점은 사용자 마스크/앵커로 저장하지 않는다.
