# 정합 분야 근거 조사와 수정 제안

조사일: 2026-09-07. 대상: 일반 2D 치과 임상사진에서 전치와 소구치를 기준으로 무치악 부위를 비교하는 DKP Registrator. 가로세로 비율 보존, SAM 마스크 중심 UI, 대응점은 선택적 보조 기능이라는 사용자 조건을 유지한다. 이번 문서는 조사·제안이며 앱이나 정합 엔진을 변경하지 않는다.

## 결론과 이전 제안의 수정

이 용도에 그대로 적용할 단일 공인 정합 알고리즘이나 보편적 허용오차는 이번 조사에서 확인하지 못했다. 실제 근거는 전문 분야 QA 권고, 일반 정합 이론, 실용 도구의 구현 관행, 치과 사진 연구로 나뉜다.

권장 방향은 **구조물별로 검증하는 비율 보존 정합**이다. SAM2/LoFTR를 우선 교체하기보다, 사용자가 지정한 기준을 엔진이 실제로 반영하고 있는지 확인하고, 한쪽만 맞은 결과를 좋은 정합으로 판정하는 문제부터 해결한다.

이전의 ‘구조물별 균형’은 무조건 동일 가중치를 주자는 뜻으로 구현하면 안 된다. 잘못 식별한 전치 대응점에 강한 가중치를 주면 소구치까지 틀어질 수 있다. **신뢰도 낮은 대응점 제외 + 공간·구조물별 독점 방지 + 서로 충돌하는 기준 감지**가 함께 필요하다. 이 조합은 문헌을 현재 사례에 적용한 설계 제안이며, 특정 지침이 지정한 표준 알고리즘은 아니다.

## 현재 구현과의 차이

현재 코드는 SAM 개체들을 union mask로 합치고, global과 masked LoFTR 점을 합산한다. RANSAC에 선택된 inlier 오차가 품질 지표의 중심이다. 사용자 대응점은 자동 추정 뒤 가중 보조점으로 들어간다. 구조물 간 합의, 독립 확인점, 관심 부위의 검증 상태는 별도로 처리하지 않는다.

앞선 합성 재현에서는 소구치 역할 120점과 전치 역할 12점의 변환이 충돌했을 때, 전치 점이 모두 제외되고 전치 잔차 22px인데도 inlier 중앙 오차 0px/pass로 표시됐다. 이는 환자 사진 진단이 아니라 현 추정·평가 방식의 편향을 보여주는 실험이다. 근거 파일: `.unlazy/wipe-diagnosis/reproduce.py`, `consensus.json`.

## 제안하는 처리 흐름

1. **기준 영역 보존:** 확정한 마스크 개체 ID를 엔진까지 유지한다. 고정상/이동상 구조물 짝을 확인할 수 있게 한다. 한쪽에만 마스크가 있을 때 전체 영역으로 조용히 대체하지 않고 현재 사용 조건을 표시한다.
2. **초기 위치 찾기:** 필요하면 전체 영상으로 거친 후보를 구한다. 사용자가 기준을 지정한 경우, 최종 적합에서는 지정 영역 밖의 점이 기준을 압도하지 못하게 한다. 전역 후보가 선택 영역 검증을 대신하지 않는다.
3. **대응점 정리:** 두 매칭 경로의 중복 점을 제거하고, 한 치아의 좁은 부분에서 나온 과밀 점을 줄인다. 신뢰도, 구조물별 총 가중치 상한, 공간 분포를 함께 고려한다. 단순 50:50 강제는 하지 않는다.
4. **여러 기준을 지지하는 변환 추정:** 후보 생성부터 여러 지정 구조물을 고려한다. 유효 점이 없는 구조물을 억지로 채우지 않는다. 필수 기준들이 서로 다른 변환을 요구하면 균등하게 틀린 중간 결과를 pass로 내보내지 않는다.
5. **비율 보존 재적합:** 최종 모델은 회전·이동·균일 배율인 similarity다. 피라미드마다 실제 이동 마스크를 누적 변환으로 옮겨 사용한다. 고정 마스크로 대신해 중요한 영역을 놓치는 경로를 없앤다.
6. **검증을 별도로 수행:** 구조물별 지원 수, 분포, 잔차를 표시한다. 계산에 사용하지 않은 확인점이 있으면 별도 잔차를 표시한다. 양쪽 기준을 만족해도 관심 부위에 독립 확인이 없으면 ‘관심 부위 검증 완료’로 승격하지 않는다.
7. **실패 시 보정:** 대응점 패널을 열어 ‘기준점 우선’ 경로를 제공한다. 먼저 수동 점으로 similarity를 구하고, 자동 보정은 이 기준을 훼손하지 않는 범위에서 검토한다. 2쌍은 계산의 최소 조건일 수 있지만 검증에는 부족하다. 가능하면 더 많은 명확한 점을 분산하고 일부를 확인용으로 남긴다.

단순 점 무작위 분할은 같은 소구치의 가까운 점이 학습/검증에 동시에 들어갈 수 있다. 구조물·공간 단위의 분리와 사용자 독립 확인점을 우선한다. 소수 점의 leave-one-out이나 bootstrap 안정성은 보조 진단이며 임상 정확도의 보증이 아니다.

## 사용 흐름과 표시

메인 마스크 바는 유지한다. 개체를 확정하면 선택적으로 이름/짝을 확인하는 작은 칩을 둔다. 치아 번호 입력을 모든 사진에서 강요하지 않는다. 대응점 UI는 기존처럼 접혀 있고, 문제가 있을 때만 이유와 ‘대응점으로 보정’ 버튼을 제공한다.

결과 정보 예시 — 아래 값은 실제 검사 결과가 아닌 문구 설계다:

| 표시 | 뜻 |
|---|---|
| 기준 1 지원됨 / 기준 2 확인 필요 | 지정 기준이 모두 변환을 지지하지는 않음 |
| 기준 구조물 간 불일치 | 기준들이 서로 충돌하거나 대응이 잘못됐을 가능성 |
| 독립 확인점 없음 | fitting 오차만 있으며 별도 위치 검증은 없음 |
| 관심 영역: 비교용 표시 | 무치악 부위를 관찰하기 위한 표시이며 정합의 정답 라벨이 아님 |
| 사용자 확인됨 | 자동 계산 완료와 구분된 수동 검토 상태 |

한 개의 마스크라도 넓은 악궁을 포함할 수 있으므로 ‘개체가 1개면 무조건 실패’ 같은 규칙은 쓰지 않는다. 개체 수와 공간 분포·유효 지지 여부를 함께 평가한다. ‘원근 차이 확정’ 같은 자동 진단도 피한다. 불일치의 원인은 가림, 오매칭, 실제 변화, 촬영 기하 등 여러 가지일 수 있다.

## 구현 우선순위

### 추가 제안: 자동 앵커 추천으로 재정합

사용자 제안에 따라, 기본 자동 정합 후 선택 구조물의 지지가 부족하거나 사용자가 결과에 만족하지 않을 때 사용할 보조 경로를 추가한다. 이 항목은 설계 제안이며 아직 구현되지 않았다.

- **진입:** 정합 결과 작업대 아래에 상시 보이는 ‘정합 안내’ 메시지 영역을 둔다. 기본 문구는 ‘정합 결과가 마음에 들지 않으면 아래 방법으로 보정해 보세요.’이며 자동 실패 판정이 없어도 네 가지 보정 동작에 접근할 수 있다. 팝업이나 사용자 응답을 기다리는 질문 대신 같은 영역에서 상태를 알린다. 결과가 마음에 드는지는 시스템이 추측하지 않는다.
- **추천:** 짝지어진 마스크 개체마다 두 영상에서 실제로 대응할 근거가 있는 후보 쌍을 찾고, 신뢰도와 최소 간격·공간 분포를 함께 고려해 소수만 제시한다. 기존 RANSAC에서 살아남은 점만 재활용하면 탈락한 전치가 계속 빠질 수 있으므로 선택 구조물의 원래 후보를 다시 검토한다. 필요할 때 지원이 부족한 영역만 추가 매칭한다. 빈 격자를 채우기 위해 불확실한 점을 만들지 않는다.
- **의미:** 각 영상에 따로 격자 점을 찍거나 현재 변환으로 점을 복사하는 것은 독립적인 대응 근거가 아니다. 자동 추천은 확정 수동 앵커 및 독립 확인점과 구분한다. 사용자가 채택해도 정합 계산에 쓴 점은 검증용 확인점이 되지 않는다.
- **검토:** ‘앵커 자동 추천’ 버튼을 누르면 원본 나란히 보기와 접힌 대응점 패널을 열고 양쪽 영상에 같은 번호의 후보를 표시한다. 이 동작만으로 재정합하지 않는다. 후보 쌍 삭제·위치 수정·수동 추가를 지원하고, ‘이 점들로 재정합’을 별도 실행한다. 추천이 불가능한 구조물에는 ‘신뢰할 대응점 부족’과 수동 보정 경로를 표시한다.
- **결과:** 비율 보존 similarity로 새 후보 결과를 생성한다. 추천 실패나 취소가 기존 결과를 덮어쓰지 않게 하고, 이전/새 결과를 와이프로 비교한 뒤 채택하거나 기존 결과로 돌아간다. 추천점은 해당 사진 쌍·마스크·고정상 상태에 귀속하며 상태가 바뀌면 재검토한다.
- **방식 비교:** 추천 즉시 재정합은 빠르지만 잘못된 자동 점을 확인하기 어렵고, 완전 수동은 제어성이 높지만 부담이 크다. 권장안은 ‘추천 → 사용자 검토 → 재정합’이며 수동 보정을 함께 제공한다.
- **검증:** 소구치 쏠림에서 전치 후보가 실제로 복구되는지, 전치에 올바른 후보가 없을 때 가짜 앵커를 만들지 않는지, 기존 결과 보존과 비율 보존이 유지되는지 확인한다. 추가 매칭은 필요할 때 실행하고 유효한 기존 후보는 재사용해 재시도 지연을 줄인다.

P1의 구조물별 후보·공간 샘플링을 재사용하고 P2의 보정 흐름에 통합한다. 같은 실패 점을 화면에 다시 표시하는 것만으로는 개선이 아니며, 다른 유효 대응 근거를 확보하지 못하면 개선을 보장하지 않는다.

### 정합 안내 영역의 위치와 문구 — 사용자 피드백 반영

현재 화면에는 사진 위의 조건부 notice, 마스크/대응점 도구 바, 닫을 수 있는 우측 정보·저장 패널, 사진 아래 확대·비교 도구 바가 있다. 안내가 여러 곳에 흩어지지 않도록 다음처럼 역할을 배분한다.

| 위치 | 역할 |
|---|---|
| 사진 바로 위의 결과 기준 줄 | 현재 표시 중인 결과가 어느 고정상으로 계산됐는지와 이전 결과 여부를 표시한다. 보정 방법 설명은 넣지 않는다. |
| 사진 아래 확대·비교 도구 바 바로 다음 | ‘정합 안내’ 상시 메시지 패널. 기본 안내, 현재 작업 상태·실패 이유, 네 가지 보정 동작을 모은다. 우측 패널을 닫거나 집중 보기를 켜도 접근 가능하게 한다. |
| 마스크 대상 바 / 펼친 앵커 바 | 현재 선택 도구의 짧은 조작법만 표시한다. A/D, Z/X 등의 단축키를 이곳에 둔다. |
| 우측 정합 상세 | 구조물별 지지·오차·검증 상태 등 상세 수치. 기본 안내를 중복하지 않는다. |

안내 패널은 사진을 덮지 않는 일반 레이아웃으로, 제목·짧은 메시지·동작 한 줄을 기본으로 한다. 넓은 화면은 버튼 네 개를 한 줄, 좁은 화면은 2×2로 배치한다. 사진의 최소 작업 높이를 확보하고 작은 창에서는 페이지를 스크롤할 수 있게 하며 절대 위치로 이미지를 가리지 않는다. 각 방법의 설명은 포인터 올림과 키보드 포커스에서 확인할 수 있게 하고, 실행 후에는 해당 동작의 안내를 메시지 영역에 표시한다. 숫자는 순서가 아닌 선택지이므로 단계 완료 UI로 만들지 않는다.

기본 제목: **정합 안내**

기본 본문: **정합 결과가 마음에 들지 않으면 아래 방법으로 보정해 보세요.**

| 버튼 | 방법 설명 | 누른 뒤 동작 |
|---|---|---|
| 앵커 자동 추천 | 선택한 개체 안에서 고르게 분포한 대응점을 추천합니다. 점을 확인한 뒤 다시 정합하세요. | 원본 나란히 보기로 이동하고 앵커 패널을 펼쳐 추천 점 쌍을 표시한다. 기존 수동 점은 보존한다. |
| 앵커 직접 찍기 | 두 사진에서 같은 위치를 직접 짚어 정합 기준을 지정하세요. | 원본 나란히 보기·앵커 패널을 열고 수동 입력을 시작한다. |
| 마스크 재선택 | 기준으로 삼을 구조물을 다시 선택한 뒤 정합하세요. | 마스크 편집으로 이동한다. 누르는 즉시 기존 마스크를 초기화하지 않는다. |
| 미세조정 | 사진을 보며 위치·회전·균일 배율을 조금씩 조절하세요. | 현재 유효 결과의 미세조정 도구를 연다. 결과가 없으면 비활성화하고 이유를 표시한다. |

상태별 메시지는 같은 패널의 고정된 위치에서 교체한다. 긴 오류는 ‘자세히’로 펼친다. 기본 방법 네 가지는 유지하되 실행 불가능한 동작만 이유와 함께 비활성화한다.

| 상태 | 표시 문구 |
|---|---|
| 결과 표시 기본 | 정합 결과가 마음에 들지 않으면 아래 방법으로 보정해 보세요. |
| 선택 기준 일부 불일치 | 선택한 기준 일부가 잘 맞지 않습니다. 앵커를 보정하거나 마스크를 다시 선택해 보세요. |
| 추천 중 | 선택한 개체 안에서 대응점을 찾고 있습니다. |
| 추천 완료 | 추천 앵커를 표시했습니다. 두 사진의 같은 위치인지 확인한 뒤 ‘이 점들로 재정합’을 누르세요. |
| 추천 부족 | 일부 개체에서 신뢰할 대응점을 찾지 못했습니다. 앵커를 직접 찍거나 마스크를 다시 선택해 주세요. |
| 직접 입력 | 기준 사진의 한 점을 클릭하고 A를 누른 뒤, 현재 사진의 같은 위치를 클릭하고 A를 누르세요. |
| 마스크 편집 | 기준으로 삼을 구조물을 선택하고 Z로 확정한 뒤 다시 정합하세요. |
| 미세조정 | 위치·회전·균일 배율을 조절해 맞춰 보세요. |
| 실패, 이전 결과 있음 | 이번 정합은 실패했습니다. 이전 결과를 유지하고 있습니다. 아래 방법으로 보정해 보세요. |
| 실패, 이전 결과 없음 | 정합 결과를 만들지 못했습니다. 앵커를 지정하거나 마스크를 다시 선택해 보세요. |

오래된 결과 표시 여부는 사진 위 결과 기준 줄에서도 계속 보인다. 진행·실패 메시지가 기본 문구보다 우선하며, 사진을 전환하면 해당 사진의 상태로 바꾼다. 늦게 끝난 다른 사진의 추천 응답이 현재 사진의 점이나 안내를 덮어쓰지 않게 사진 쌍·입력 버전을 검사한다. 진행 안내는 접근성 live region을 사용하되 포커스를 강제로 옮기지 않는다. 추천/수동 입력 진입처럼 사용자가 요청한 도구 전환에서만 조작 가능한 컨트롤로 자연스럽게 이동한다.

| 단계 | 구현 | 수용 기준 |
|---|---|---|
| P0: 잘못된 통과 방지 | 개체 정보·부위별 지표·검증 상태, 마스크 미사용 표시, 실제 이동 마스크 변환 | 한쪽 기준만 맞는 앞선 재현을 무경고 통과시키지 않는다. |
| P1: 추정 개선 | 중복 제거, 공간 샘플링, 구조물별 독점 제한, 여러 구조물에서 후보 생성 | 올바른 대응을 가진 불균형 입력에서 양쪽 잔차가 줄고, 오매칭을 강제해 결과를 악화시키지 않는다. |
| P2: 보정과 검증 | 기준점 우선 similarity, 계산점과 확인점 분리, ROI 검토 안내 | 확인점이 추정에 들어가지 않으며, 검증 부재/불일치를 구분한다. |
| P3: 알고리즘 대안 비교 | LoFTR 대비 LightGlue 등의 후보, robust estimator 대안 | 같은 환자 단위 분리 검증셋에서 관심 부위 오류·잘못된 통과율·속도·메모리를 함께 비교한 뒤 선택한다. |

P0만으로 정확도가 모두 좋아지는 것은 아니다. 우선 잘못된 확신을 줄이고, P1에서 실제 추정을 개선하며, P2에서 어려운 사례를 제어한다.

## 검증 설계

- 알고 있는 similarity 변환을 적용한 합성 사진: 이미지 전체/관심 위치의 변환 오차와 비율 보존을 확인한다.
- 점 수가 한쪽으로 치우친 입력, 전치의 잘못된 매칭, 마스크 누락, 가림을 각각 분리해 시험한다.
- similarity로 설명할 수 없는 원근·깊이 차이 입력: 왜곡 없이 한계를 보고하는지 확인한다.
- 실제 사진은 촬영 시기·환자별로 학습/튜닝/평가를 분리한다. 사진만 섞으면 같은 환자 치아가 양쪽에 들어가 평가가 낙관적일 수 있다.
- 정합 계산에 쓰지 않은, 반복해서 식별 가능한 안정 지점으로 2D 위치 오차를 평가하고 관찰자 간 표시 차이도 기록한다. 수술로 변한 조직 경계는 같은 위치의 정답이라고 가정하지 않는다.
- 중앙값만 보고하지 않는다. 높은 분위의 오차, 구조물 누락률, 실제로 틀렸는데 통과한 비율, 계산 실패율, 실행 시간을 함께 본다.
- 픽셀 오차는 평가 해상도와 함께 표시한다. 영상 대각선으로 정규화한 값은 크기 비교 보조 지표이며 임상 허용치가 아니다. 물리 보정 없이 mm로 환산하지 않는다.
- 허용오차는 목적과 독립 검증 결과를 바탕으로 정한다. AAPM의 다른 영상용 수치나 위 전치부 연구의 각도를 그대로 합격 기준으로 쓰지 않는다.

현재 UI와 엔진 구조는 출발점으로 사용할 수 있다. 그러나 현재의 단일 inlier 중앙 오차와 pass 표시는 사용자가 의도한 ‘두 기준 구조물 사이 수술 부위 비교’의 신뢰도를 판단하기에 부족하다는 것이 이번 재검토의 결론이다.
